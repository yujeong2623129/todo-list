# To-Do List

HTML, CSS, JavaScript를 학습하며 제작한 할 일 관리 웹 애플리케이션입니다.

## 주요 기능

- 할 일 추가 및 삭제
- 체크박스를 이용한 완료 상태 변경
- 전체 할 일 및 완료한 할 일 개수 표시
- Enter 키로 할 일 추가
- localStorage를 활용한 데이터 저장 및 복원
- 모바일 화면을 고려한 반응형 디자인

## 사용 기술

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Web Storage API (localStorage)

## 프로젝트 구조

```text
todo-list/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 실행 방법

1. 프로젝트 파일을 다운로드합니다.
2. 로컬 웹 서버에서 `index.html`을 엽니다.
3. 입력창에 할 일을 작성하고 추가 버튼을 누릅니다.
4. 체크박스로 완료 상태를 변경하거나 삭제 버튼으로 할 일을 제거할 수 있습니다.

## 학습 내용

- DOM 요소 선택 및 조작
- 이벤트 리스너를 활용한 사용자 입력 처리
- 배열과 객체를 활용한 데이터 관리
- JSON 및 localStorage를 이용한 데이터 저장
- 함수를 활용한 기능 분리

## 향후 개선 계획

- 할 일 수정 기능
- 완료 및 미완료 항목 필터링
- 마감일 설정 기능
